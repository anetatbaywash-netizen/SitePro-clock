2

Click "Create a project" → name it anything (e.g. "ShiftClock") → Continue → Create Project

3

In the left menu: Build → Realtime Database → Create Database

Choose any location, then select "Start in test mode" → Enable

4

Click the gear icon (top left) → Project settings

5
